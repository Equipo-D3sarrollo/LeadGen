# LeadGen — notas guardadas (proyecto "lead gen")

- LeadGen debe ser una herramienta completa pero que no piense por sí misma, hecha para que la usen IA y adaptable a distintos proveedores.
- Lety es la IA de ventas de Telcobras; en LeadGen se usarán Lety (ventas), OpenAI (redacción) y Claude como opcional para tareas complejas y cortas.
